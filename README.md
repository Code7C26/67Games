# 67Games
Un juego de estrategia inspirado en la propagación de enfermedades, desarrollado con Godot Engine. El objetivo es crear una experiencia donde el jugador deba evolucionar un patógeno, adaptarse a distintos desafíos y lograr su propagación a nivel mundial.
