PATOGEN MALL — V4 GAMEPLAY POLISH
==================================

Gameplay-first pass while preserving visual polish.

COLLISION / ACCESS
- Removed the legacy editor collision layout at runtime instead of merely disabling children.
  This prevents invisible/ghost geometry from competing with the new collision source.
- Fixed east/west storefront orientation.
  * CINEMA: door on west side.
  * ARCADE: door on west side.
  * MARKET: door on west side.
  * CAFE: door on east side.
- Door gaps are now real collision openings and are wider than V3.
- SPORTS door widened to 128 px.
- Added a 160 px high south promenade and wide connectors so SPORTS is directly reachable.
- Added collision for visible public benches, central atrium benches, planters and escalator bodies.
- Fountain keeps a dedicated circular collision.

BOT / AI READINESS
- Added a dedicated NavigationRegion2D generated by mall_main.gd.
- Navigation covers public circulation, south loop, store interiors and explicit doorway connectors.
- Added documentation explaining the one remaining integration caveat: bots that directly edit
  position instead of using physics/navigation can still ignore collision.

VISUAL POLISH
- Storefront glass is now actually split around the doorway instead of drawing a continuous wall.
- Improved the south circulation loop to read as a real shopping-mall promenade.
- Added cinema marquee/screens, arcade machine banks, market aisles, cafe tables and a clearer sports layout.
- Added clearer escalator direction cues, tile rhythm, entrances and public furniture.
- Kept HOT/COLD visual indicators restrained so gameplay information does not dominate the mall.

HANDOFF / EXPORT
- Added MAP_INTEGRATION.md for the teammates who already have mechanics + sprites.
- Added Godot 4.7.x export presets for Windows and Linux as a starting point.
- Main scene remains standalone and ready to merge into the larger project.
- Added a dedicated cinema feeder lane so the corrected west-side cinema entrance
  is reachable from the north promenade rather than becoming a dead end.
